# Xenox Short (Offline APK)

No server, no database, no hosting. Everything runs inside the phone.

## Build the APK (GitHub)
1. Upload all files of this project to a new GitHub repository (branch `main`).
2. GitHub > Actions > "Build Android APK" runs automatically (or press "Run workflow").
3. When it finishes, open the run and download the artifact `xenox-short-apk` (contains `app-debug.apk`).

If an older HBX Short (signed with another key) is installed, uninstall it first.
